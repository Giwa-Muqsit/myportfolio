# Giwa Muqsit Olufowobi — Portfolio

Professional portfolio for Giwa Muqsit Olufowobi, Founder of Pinnacle Tech Services. Built with React, TypeScript, Vite, and Tailwind CSS.

Live site: https://giwa-muqsit.netlify.app/

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/` and can be deployed to Netlify or any static host.
